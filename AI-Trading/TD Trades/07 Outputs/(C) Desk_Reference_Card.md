## QUICK MODEL IDENTIFIER (30 seconds)

### 🔴 Do I See a REV MODEL?
**Checklist:**
- [ ] Price swept ERL (external range high/low)
- [ ] Structure low formed after ERL sweep
- [ ] Impulsive candle below structure (neckline break)
- [ ] IRL (fair value) identified above entry
- [ ] ERL target visible above fair value
- [ ] Can I set stop ~20p or prev wick?

**If ALL checked:** TAKE REV MODEL  
**Entry:** Flip candle off neckline  
**SL:** ~20p below neckline or prev wick high  
**PT1:** IRL (fair value)  
**PT2:** ERL (premium)  
**Expected WR:** 85-90% (if done properly)

---

### 🔵 Do I See a CONTINUATION MODEL?
**Checklist:**
- [ ] HTF shows clear bullish (HH/HL) or bearish (LL/LH)
- [ ] Price recently swept IRL (internal range)
- [ ] Price is pulling back to fair value (not reversing)
- [ ] No reversal structure forming
- [ ] ERL target is clear above (bullish) or below (bearish)
- [ ] Can I enter on retracement + model confirmation?

**If ALL checked:** TAKE CONTINUATION  
**Entry:** After retracement into IRL + conf  
**SL:** Below structure low (or ~20p tight)  
**PT1:** IRL  
**PT2:** Full ERL  
**Expected WR:** Depends on HTF/LTF alignment

---

### 🟢 Do I See an IFVG MODEL?
**Checklist:**
- [ ] Recent fast move created visible gap
- [ ] Gap is within last 2-3 candles (FRESH)
- [ ] Price has moved away from gap
- [ ] Gap needs to be "filled" (retested)
- [ ] Clear structure supports gap fill

**If ALL checked:** TAKE IFVG  
**Entry:** Price retraces toward gap  
**SL:** Beyond gap opposite side  
**PT:** Gap fully filled + continuation  
**Expected WR:** High-prob if structure supports

---

### 🟠 Do I See an MFD MODEL?
**Checklist:**
- [ ] Major news event upcoming (CPI/NFP/FOMC)
- [ ] Pre-news thesis established (HTF bias)
- [ ] New high/low created BY the news
- [ ] Structure confirms direction (no whipsaw)
- [ ] Price NOT in chaos (wait for structure formation)

**If ALL checked:** TAKE MFD  
**Entry:** AFTER news + structure, NOT during spike  
**SL:** Outside news high/low  
**PT1:** Previous key level  
**PT2:** Larger objective  
**Expected WR:** Variable (depends on thesis)

## COMMON MISTAKES (CHECKLIST)

Before hitting "BUY/SELL," check you're NOT:

- [ ] **Forcing a model that isn't there** — If unsure, sit out
- [ ] **Ignoring HTF structure** — Always check daily first
- [ ] **Trading old FVGs** — Only fresh gaps (1-3 candles)
- [ ] **Entering during news chaos** — Wait for structure
- [ ] **Mixing models mid-trade** — Pick one, stick to it
- [ ] **Letting winners run without plan** — Scale at PT1
- [ ] **Revenge trading** — One loss ≠ take next bad setup
- [ ] **Trading outside hours** — Stick to your schedule
- [ ] **No stop loss** — ALWAYS define SL before entry
- [ ] **Chasing (FOMO)** — Best trades come to you
